## Project Overview
This project focuses on predicting house prices using Machine Learning techniques and Python.

## Objectives
- Understand and analyze housing data.
- Preprocess data for Machine Learning.
- Train a prediction model.
- Predict house prices using the trained model.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project File
- House Prediction.ipynb — Jupyter Notebook containing the project workflow.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or VS Code.
4. Run the cells in sequence.

## Learning Outcomes
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- House price prediction
